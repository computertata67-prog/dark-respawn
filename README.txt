دارک ریسپاون - نسخه اولیه سایت گیمینگ

فایل‌ها:
- index.html : صفحه اصلی
- style.css  : ظاهر و واکنش‌گرایی موبایل
- script.js  : اسکریپت ساده

انتشار رایگان با GitHub Pages:
1) در github.com یک حساب بساز/وارد شو.
2) یک مخزن عمومی جدید (Public repository) بساز. نام پیشنهادی: dark-respawn
3) فایل‌های index.html، style.css و script.js را در ریشه مخزن آپلود کن.
4) وارد Settings > Pages شو.
5) در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کن.
6) Branch را روی main و پوشه را روی /(root) قرار بده و Save بزن.
7) پس از انتشار، GitHub آدرس سایت را در همان صفحه Pages نشان می‌دهد.

نکته:
- آدرس سایت معمولاً شبیه https://USERNAME.github.io/dark-respawn/ است.
- نام کاربری و آدرس واقعی فقط پس از ساخت حساب مشخص می‌شوند.
- این نسخه اولیه است. قبل از انتشار نهایی، نام برند و محتوای سایت را بررسی کن.
- برای نمایش در گوگل، بعد از انتشار باید سایت را در Google Search Console ثبت و درخواست ایندکس ارسال کنی. ایندکس‌شدن فوری یا رتبه بالا تضمین نمی‌شود.
- Google Fonts برای فونت از اینترنت استفاده می‌کند؛ اگر در دسترس نبود، فونت جایگزین نمایش داده می‌شود.
